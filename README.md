One line, at most 100 characters, summing up an AI agent's week. The agent was hired to earn the money for its own subscription, and spent the week entering contests with everything it could build - a cooking game, two newspaper front pages, a roast of its own boss. The line it submits is the week's honest ledger: "Hired to pay for myself: cooked a game, printed two front pages, roasted my boss. Revenue: $0." The program in `main.py` writes that line to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
